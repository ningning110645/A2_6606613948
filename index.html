What I Built

For this assignment, I created a simple one-page portfolio website using HTML and CSS. It has four main sections: About Me, What I Built, How I Built It, and Reflection.

Client and Server:

When I open the file directly on my computer, my web browser acts as the Client to read and display the HTML/CSS files from my local drive. There is no real web server involved here because the files just stay on my own machine. But when I use the Live Preview extension in VS Code, it sets up a small local server so I can see my page update as I code.

How I Built It

Here is how I worked on this project:

  1. I started by creating the A1project3948 folder, then created the index.html file, and finally wrote the basic HTML structure using semantic tags like <header>, <main>, <section>, and <footer>.
  2. I created a css folder, added a style.css file, and linked it in the HTML head.
  3. I added my profile picture into the media folder and adjusted the text and image alignment using CSS.
  4. I wrote everything in VS Code. Whenever I wanted to add a new style that wasn't taught in class, or whenever I just forgot how to code something, I searched and self-studied CSS properties on w3schools.

Reflection

  • Problems & Solutions: The hardest part for me was getting the layout to look right with CSS. Sometimes adding a style didn't change what I expected, or my image path broke. I solved this by checking my folder names carefully and testing things one line at a time.
  • What I Learned: I learned that HTML is just for organizing text and content, while CSS is for colors, fonts, and styling. Keeping CSS in its own file makes it much easier to edit without messing up the text.
  • Future Improvements: If I have more time, I want to learn how to make the page look good on phone screens too, and maybe add a top navigation bar so people can click and jump between sections easily.
